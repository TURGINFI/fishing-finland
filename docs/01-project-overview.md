# Project Overview

## Project title
Fishing in Finland for Foreign Anglers

## Project idea
An English web platform for foreign fishing enthusiasts in Finland. The platform provides public fishing information and member-only functions.

## Target users
- foreign residents in Finland
- exchange students
- tourists interested in fishing
- beginner anglers who need English information

## Main value
- easier access to regulations
- fish species information in English
- event discovery and registration
- community blog posting
- catch tracking and yearly goals
- partner gear recommendations
