# User Requirements

1. As a visitor, I want to browse Finnish fishing regulations so that I can understand legal rules before fishing.
2. As a visitor, I want to browse fish species information and fishing methods so that I can learn what to catch and how.
3. As a visitor, I want to browse public content such as events, blogs, fishing spots, and gear recommendations before creating an account.
4. As a user, I want to register with email and password so that I can access member-only features.
5. As a user, I want to log in securely so that I can manage my account.
6. As a user, I want to edit my profile so that I can personalize my account.
7. As a user, I want to register for fishing events so that I can participate in activities.
8. As a user, I want to submit blog posts for moderation so that I can share fishing experiences.
9. As a user, I want to receive platform messages in my inbox so that I can stay informed.
10. As a user, I want to record catches and set yearly fishing goals so that I can track my progress.
11. As a user, I want to delete my account so that I can remove my data if I stop using the platform.
