# AI Usage

AI is used as:
- a personal assistant for writing and structuring documentation
- a product manager support tool for clarifying scope and workflows
- a coding assistant for refining Django, HTML, CSS, and JavaScript
- a testing support tool for suggesting test cases and validation flows
- a deployment assistant for Docker and environment setup guidance

## Best practices
1. Final decisions are made by the developer.
2. AI suggestions are reviewed before use.
3. AI helps structure rough ideas, but does not replace product judgment.
4. Outputs are adapted to the real project context.
